# Sources and files

The VPK installs the Vita application. The original PC game's `game/` folder provides the game content.

## Documented destination

```
ux0:/app/RNPYSS004/game/
```

- Keep the title-ID folder exactly as shown.
- Copy `game/` inside the title directory, not beside it.
- Do not rename or flatten the content folder.

## Original game

Obtain the original game from the [Steam listing](https://store.steampowered.com/app/1466690/Sakura_Succubus_4/).

> [!IMPORTANT]
> **MUST KNOW!!** Do not commit original game files to the repository or attach them to public issues.
