# Install on PS Vita

This page follows the port's README for the documented VitaShell installation method.

1. Download the VPK.
2. Extract it as an archive into a new folder.
3. Transfer the extracted folder to the Vita.
4. Open **VitaShell**.
5. Highlight the folder without opening it.
6. Press **TRIANGLE**, choose **More**, then **Install folder**.
7. Confirm the prompts.
8. Obtain the original game from [Steam](https://store.steampowered.com/app/1466690/Sakura_Succubus_4/).
9. Copy its `game/` folder to:

```
ux0:/app/RNPYSS004/
```

> [!IMPORTANT]
> **MUST KNOW!!** The original game's `game/` folder is separate from the port VPK. The final layout should be `ux0:/app/RNPYSS004/game/`.
