# FAQ

## Does the port include the original game?

No. The original game's content is separate from the Vita port.

## Where do I get the original game?

Use the official [Steam listing](https://store.steampowered.com/app/1466690/Sakura_Succubus_4/).

## What is the required content path?

`ux0:/app/RNPYSS004/game/`

## Where should I report a problem?

Open an issue in the [port repository](https://github.com/SilverCrow2323/Sakura-Succubus-4-Vita/issues). Include the release version and reproducible steps, not copyrighted game files.
