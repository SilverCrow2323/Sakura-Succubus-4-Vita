# Troubleshooting

Check the VPK installation and the exact release-specific game-file path before reinstalling.

## Common checks

| Symptom | First check |
|---|---|
| App is missing from LiveArea | Confirm the VPK/folder installation completed |
| App opens but content is missing | Check that the original game's `game/` folder is in the documented title-ID directory |
| Files are beside the title folder | Move them inside the correct title-ID directory |
| A menu behaves incorrectly | Record the exact menu, save slot and reproduction steps |

## Known issue

The README reports that the **Settings** and **Load/Save** menus can sometimes be glitchy. **Quick Load/Save** is reported to work without issues. The README notes this may be common in newer Winged Cloud games.

- Prefer Quick Load/Save when the full menu behaves incorrectly.
- Record the exact menu, save slot and reproduction steps when reporting a problem.

## Report a problem

Include port version, Vita model/firmware if known, original game version, exact path and complete error text. Do not attach copyrighted game data.
