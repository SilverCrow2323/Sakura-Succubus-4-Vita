# Wiki source and publishing

The `wiki-source/` directory is the canonical source for the practical GitHub Wiki.

## Page rules

- One topic per page.
- Start with a short explanation and one concept per bullet.
- Use **MUST KNOW!!** only for required prerequisites or important safety/compatibility notes.
- Use **Optional** only for non-essential enhancements.
- Leave basic steps unlabelled.
- Keep original game and mod content separate from the port.
- Do not invent paths absent from release documentation.
- Never publish copyrighted game files.

## First-time Wiki activation

1. Open the [GitHub Wiki](https://github.com/SilverCrow2323/Sakura-Succubus-4-Vita/wiki).
2. Create and save a page titled **Home**.
3. From a clone with Git credentials, run `sh tools/publish_wiki.sh`.

Edit `wiki-source/`, not only the live Wiki.
